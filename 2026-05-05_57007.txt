<p>Consider the world’s simplest database:</p>
</blockquote>
<blockquote>
<pre><code>#!/bin/bash

db_set () {
  echo &quot;$1,$2&quot; &gt;&gt; database
}

db_get () {
  grep &quot;^$1,&quot; database | sed -e &quot;s/^$1,//&quot; | tail -n 1
}
</code></pre>
